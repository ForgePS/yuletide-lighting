## Limitations of COMPLETE_WITH_LIMITATIONS

Phase 0 intentionally does **not**:

- Fix lint failures
- Flip fail-open to fail-closed
- Remove mocked features
- Migrate data
- Quarantine legacy routers into `active/compatibility/legacy` folders yet

Those belong to later phases. Phase 0 **does** establish the branch, inventories, risk register, and a nonzero-exiting `production:check` gate.
